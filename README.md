# Osaka Job Search

Job search planning repository for Osaka and Nara area roles related to industrial machinery, press machinery, overseas sales, technical sales, and project coordination.

## Purpose

This repository organizes job search strategy, company research, application tracking, resume materials, interview preparation, and portfolio links.

## Target Roles

| Role Type | Priority | Notes |
| --- | --- | --- |
| Technical sales | High | Industrial machinery, press machinery, automation |
| Overseas sales | High | Korea-Japan business, English/Japanese communication |
| Project coordinator | High | Installation, relocation, dismantling, vendor coordination |
| Service engineer / field coordinator | Medium | Consider if salary and conditions are acceptable |

## Target Area

| Area | Priority |
| --- | --- |
| Osaka | High |
| Nara | High |
| Hyogo / Kyoto | Medium |
| Other Japan regions | Low, only if conditions are strong |

## Minimum Conditions

| Item | Target |
| --- | --- |
| Annual salary | 6,000,000 JPY or higher preferred |
| Monthly salary | 350,000 JPY or higher preferred |
| Commute | Osaka/Nara area preferred |
| Work type | Industrial machinery, press, overseas business, technical sales, PM |
